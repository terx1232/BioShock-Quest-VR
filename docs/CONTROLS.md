# Controls

| Action | Quest control |
| --- | --- |
| Move / turn | Left / right stick |
| Fire weapon | Right trigger |
| Wrench attack | Swing the right hand |
| Plasmid | Left trigger |
| Interact / search | A |
| Close / back | B |
| First aid / EVE | X / short Y |
| Hack | Left grip or hold Y |
| Ammo type | Right grip |
| Pause / map | Tap / hold left Menu |
| Map / weapon selection | Hold Menu + A / B |
| Objectives / audio diary | Hold Menu + X / Y |

In menus, aim the white ray and use the right trigger. Keep Menu held while pressing the second button for shortcuts. Wrench attacks use hand movement, not trigger presses.
